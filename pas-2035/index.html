PAS 2035 retrofit cost (UK 2026)

PAS 2035:2023 explained as cost line items: Assessor £400-800, Coordinator £1,500-3,500, Designer (Path B/C), monitoring. When mandatory, when voluntary.

When PAS 2035 is mandatory

PAS 2035 is required for any retrofit funded by ECO4, GBIS, the Social Housing Decarbonisation Fund, the Home Upgrade Grant or the Warm Homes Plan. It is currently voluntary for a standalone Boiler Upgrade Scheme heat-pump install where no other grant is being claimed.
